# 📱 ReciclaAE

**TelaWEB** é uma aplicação web desenvolvida em C# com ASP.NET, com o objetivo de orientar e facilitar o descarte correto de smartphones. A plataforma oferece funcionalidades para pessoas físicas e jurídicas, permitindo cadastro, login, 
envio de propostas e gerenciamento de celulares para o descarte.

## 🎯 Objetivo

Ajudar usuários que não sabem a maneira correta de descartar smartphones, conectando-os a processos de reciclagem ou reutilização através de uma interface amigável e funcional.

## 🚀 Funcionalidades

- Cadastro e login para **Pessoa Física** e **Pessoa Jurídica**
- Tela de **Dashboard** com visão geral
- Tela para **Enviar Proposta** para o descarte
- Tela para **Cadastrar Celular** a ser descartado
- Tela para **Consultar Celular** já registrado no sistema
- - Tela para **Consultar Proposta** Aceitando ou negando

## 🧰 Tecnologias Utilizadas

- C#
- ASP.NET MVC / ASP.NET Core
- Entity Framework
- HTML, CSS e JavaScript 
- SQL Server
